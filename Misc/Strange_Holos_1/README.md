## Description

A holographic sign appears on the wall of a rain-soaked Glittercity alley. The glyphs are unfamiliar, but something about the writing system feels oddly familiar to anyone who grew up watching a galaxy far, far away.

## Solution

### Steps

**1. Identify the writing system**

The glyphs on the holographic sign are written in **Aurebesh** — the Star Wars fictional alphabet used to write Galactic Basic. Each Aurebesh character maps 1:1 to an English letter (A–Z), with additional single glyphs for digraphs such as CH, AE, EO, NG, OO, and TH.

**2. Note the tricky character**

The `=`-looking glyph in the sign is not an equals sign — it is **H (Herf)** in Aurebesh. The two horizontal bars stacked on top of each other make it easy to mistake for `=`.

**3. Decode the inscription**

Reading the Aurebesh glyphs left to right gives:

```
NERF HERDER
```

**4. Read the flag**

The decoded Aurebesh inscription is the flag itself.
