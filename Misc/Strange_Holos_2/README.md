## Description

Another holographic inscription appears on a Glittercity wall. Eight glyphs glow in neon — a different script this time, angular and aggressive.

**Attachments:** `space2-glitter.png`

## Solution

### Steps

**1. Identify the writing system**

The 8 glyphs on the wall belong to **Klingon pIqaD** — the fictional script from Star Trek used to write the Klingon language. Each glyph maps to a Latin letter.

**2. Decode the glyphs**

Reading the 8 pIqaD characters left to right and mapping each to its Latin equivalent:

```
B O L D L Y G O
```

**3. Recognize the reference**

"BOLDLY GO" is a direct reference to the iconic Star Trek phrase *"to boldly go where no one has gone before"* from the opening monologue of the series.

**4. Read the flag**

The decoded inscription is the flag itself.

## Flag

```
BOLDLY GO
```
